
# 🫁 Pneumonia Detection using CNN (MATLAB)

A Convolutional Neural Network (CNN) project built in MATLAB for classifying chest X-ray images into **Normal** and **Pneumonia** cases.

---

##  Project Preview
  Deep Learning model for medical image classification  
  Input: Chest X-ray images  
  Output: Normal / Pneumonia prediction  
  Built using MATLAB Deep Learning Toolbox  
  Evaluated using accuracy + confusion matrix  

---

##  Quick Demo
1. Load trained model (`ScratchCNN_Improved.mat`)  
2. Run `PneumoniaInterfaceImprovedversion.m`  
3. Select X-ray image  
4. Get prediction result instantly  

---

##  Output Example
 Input: Chest X-ray image  
 Prediction: **Pneumonia (or Normal)**  
 Confidence level display
